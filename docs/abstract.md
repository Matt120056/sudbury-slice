# Sudbury Slice: Abstract
**By:** Matt Pheaton

**The problem.** ...
As of right now the problem is that the website is very static and lacks personality and more importantly functionality.
all of the main questions someone would have when entering a resturant should be answered by the website but as of right
now all that the user gets is a picture and some basic menu options. if someone has an allergy or something like that they
need to go ask instead of already knowing by the info on the website.
**Who it is for.** ...
from my best guess the website is more for if an event organizer wants to use their services for catering and needs all of the information upfront and center
to avoid any confusion or possible loss of business. as well as when a birthday party may want to book the place out and then again they would ask how,where,when,allergies,
restrictions, etc.
**Why it matters.** ...
With the app, customers can see every topping and read real ratings before ordering, so they choose faster and with more confidence. Moose gets honest star ratings
from real customers, so he can finally settle the best ever pizza argument with data instead of on a gut feeling.
**What the app must remember.** ...
It must remember that a lunchtime regular with a vegan diet can check every pizza’s toppings in seconds and pick one that other customers have rated highly,
instead of guessing from a crooked photo. For Moose, the star ratings become evidence, so choosing which pizzas to promote or drop no
longer depends on the opinion that he may have, he can directly know  which pizzas he should promote.
